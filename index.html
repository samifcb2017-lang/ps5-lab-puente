Empieza por http:// e incluye la IP del PC, el puerto, la clave y la barra final. Escríbela con el teclado de la consola o pégala si la interfaz lo permite.

JavaScript pendiente. Espera a que se active el botón.

  1. Servidor encendido. Mantén abierta la ventana del servidor en el PC.
  2. Misma LAN. PC y PS5 deben poder comunicarse en tu red doméstica.
  3. Sesión actual. El enlace principal resuelve la clave nueva automáticamente. Solo la alternativa manual necesita copiar de nuevo la URL completa al reiniciar.

El campo no se envía al alojamiento público ni se guarda por el código de esta página. El navegador puede conservar historial o datos de sesión. Comparte solo la dirección pública del puente, nunca la URL LAN con su clave.

Una ruta C:/Users/…/index.html es un archivo del PC, no una URL pública ni una dirección accesible desde PS5.

La apertura de enlaces locales depende de la vista web de PS5. Este puente no concede acceso a archivos internos.
